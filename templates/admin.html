接入其他软件

    
游戏插件、按键精灵、AutoHotkey、易语言、Delphi、VB6、Go、PHP、Electron、脚本工具……只要你的软件能发 HTTP 请求，就能接入卡密系统。


    

      
      
      
    


    

      
三步接入

      
1️⃣ 在上方选择要接入的网站或 App（没有就去「+ 添加网站」用「自动生成」建一个标识）

      
2️⃣ 点「查看接入代码」，选你的软件类型，整段复制

      
3️⃣ 用户首次打开软件输卡密 → 调 /api/app/verify；之后每次启动调 /api/app/check 复核

    


    

      要点说明
      
两个接口：/api/app/verify 首次激活（开始计时）；/api/app/check 后续复核（不重复计时，失效返回 ok:false）。

      
三个请求头：X-Kami-App 你的标识、X-Kami-Code 用户卡密、X-Kami-Device 机器码（建议填，用于一台设备限制）。

      
判定通过：返回 JSON 里 "ok":true 即放行，否则按 message 提示用户并退出程序。

      
机器码怎么取：Windows 用电脑名 %COMPUTERNAME% 或 wmic csproduct get uuid；安卓用 Settings.Secure.ANDROID_ID；其他软件取任意本机固定唯一字符串即可。
